# Community Connect SA

## About the Project

Community Connect SA is a website designed to help South African high school learners find verified community service and volunteering opportunities.

## Website Pages

- Home
- About
- Services
- Resources
- Enquiry
- Contact
- FAQ

## Technologies Used

- HTML5
- 
- JavaScript

## Purpose

The purpose of this website is to connect learners with community service opportunities and provide useful information and resources.
